# Career and integration sources

Career sources rechecked November 8, 2026; integration research checked November 7. These links document the examples and host integration approach, not a promise of native verification.

## Career frameworks

- [Monzo engineering progression framework v4.0](https://monzo.com/documents/engineering-progression-framework-v4-0.pdf). The document states February 13, 2025 as its update date. It distinguishes scope and impact while allowing different strengths at the same level.
- [GitLab development career framework](https://handbook.gitlab.com/handbook/engineering/careers/matrix/development/). The page records a March 12, 2026 update. Its linked role pages provide company-specific expectations.
- [GitLab staff development expectations](https://handbook.gitlab.com/handbook/engineering/careers/matrix/development/staff/). The examples emphasize technical ownership, enabling teammates, and connecting decisions to the business.
- The current generic progression prompts were independently rewritten from these public sources on November 8, 2026. Screenshot images are not distributed. Company titles are not treated as equivalent.

Recent public Google and SanDisk engineering ladders were not verified during this research. Nail does not claim to include their current expectations.

Company and product names identify reference sources or compatibility, not sponsorship or endorsement.

## Host documentation

- [OpenAI plugin packaging](https://developers.openai.com/plugins/build/plugins) describes plugin manifests and trusted local hooks.
- [Codex hooks](https://learn.chatgpt.com/docs/hooks) documents hook events and their current limitations.
- [Claude Code hooks](https://code.claude.com/docs/en/hooks) documents command hooks and lifecycle events.
- [Cursor hooks](https://cursor.com/docs/hooks) documents JSON input and output for host hooks.
- [Gemini CLI hook reference](https://geminicli.com/docs/hooks/reference/) documents agent and lifecycle hooks.
- [OpenAI Claude-plugin submission guidance](https://developers.openai.com/plugins/guides/submit-claude-plugin) distinguishes repository-installed hooks from public directory submission.

Host APIs can change. Record the tested host version in verification results when changing an adapter.
