# Report a security problem

Do not post real performance notes, tokens, or private company information in a public issue.

Use [GitHub's private vulnerability reporting](https://github.com/yaro-work/nail-performance-review/security/advisories/new), which is enabled for this repository.

Include a minimal reproduction using invented data, the affected version, and the effect on stored records or host configuration.

nail-performance-review is a local filesystem tool. Your AI tool and operating system control access to the performance folder. It does not add encryption or a remote backup service.

Read the [privacy guide](docs/privacy.md) for data handling and export limits.
